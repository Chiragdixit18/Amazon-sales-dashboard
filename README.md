# 📊 Amazon Sales Dashboard (Power BI)

## 📝 Overview

This Power BI dashboard provides an interactive analysis of Amazon sales performance. It includes insights into revenue trends, product categories, regions, and customer behavior — helping identify key growth opportunities and business performance metrics.

## 🚀 Features

* Dynamic filters for category, region, and time period
* KPI cards for revenue, profit, and order volume
* Trend analysis of monthly and yearly sales
* Product performance comparison
* Customer segmentation and purchase behavior insights

## 🧠 Tools & Technologies

* **Power BI Desktop**
* **Dataset:** Amazon Sales Data (cleaned and transformed for analysis)
* **Visualization Techniques:** DAX measures, data modeling, and Power Query transformations

## 📂 File Included

* `AMAZONDASHBOARD.pbix` — The Power BI dashboard file.

## ⚙️ How to Use

1. Download the `.pbix` file from this repository.
2. Open it in **Power BI Desktop** (latest version recommended).
3. Interact with the visuals and explore the data insights.

## 📈 Insights Highlights

* Top-selling categories and regions
* Monthly revenue and profit trends
* Customer retention and order frequency
* Product-wise contribution to total revenue
